# Django Framework – Complete Guide

## 1. Introduction to Django

Django is a high-level Python web framework used to develop secure, scalable, and maintainable web applications. It follows the Model-Template-View (MTV) architectural pattern and provides many built-in features that help developers build applications quickly.

Django was designed to make web development easier by reducing repetitive coding tasks. It includes features such as authentication, database management, URL routing, form handling, an administration panel, and security protection.

Django is widely used for building websites, content management systems, e-commerce platforms, dashboards, social networking applications, and REST APIs.

## 2. Why Use Django?

Django is popular because it provides many useful features out of the box.

Main advantages:

- Fast application development.
- Built-in authentication system.
- Automatic administration panel.
- Powerful Object Relational Mapper (ORM).
- Database integration.
- Secure password management.
- URL routing system.
- Reusable application structure.
- Scalability for large projects.
- Strong community support.

Django follows the principle of Don't Repeat Yourself (DRY), which encourages developers to avoid unnecessary duplication of code.

## 3. Python Knowledge Required

Before learning Django, developers should understand Python fundamentals.

Important Python concepts include:

- Variables and data types.
- Conditional statements.
- Loops.
- Functions.
- Lists and dictionaries.
- Classes and objects.
- Inheritance.
- Exception handling.
- Modules and packages.
- File handling.

Understanding object-oriented programming is especially useful because Django uses Python classes extensively.

## 4. Installing Django

Django requires Python and pip.

Check Python version:

```bash
python3 --version
```

Check pip:

```bash
pip3 --version
```

Create a virtual environment:

```bash
python3 -m venv django_env
```

Activate the environment:

```bash
source django_env/bin/activate
```

Install Django:

```bash
pip install django
```

Check Django version:

```bash
django-admin --version
```

Virtual environments help keep project dependencies separate from other Python applications.

## 5. Creating a Django Project

To create a new Django project, use:

```bash
django-admin startproject myproject
```

Move into the project directory:

```bash
cd myproject
```

Start the development server:

```bash
python manage.py runserver
```

Open the following address in your browser:

http://127.0.0.1:8000/

You should see the default Django welcome page.

## 6. Django Project Structure

A typical Django project contains the following files:

```text
myproject/
    manage.py
    myproject/
        __init__.py
        settings.py
        urls.py
        asgi.py
        wsgi.py
```

Explanation:

- manage.py: Runs administrative project commands.
- settings.py: Contains project configuration.
- urls.py: Defines URL routing.
- asgi.py: ASGI application entry point.
- wsgi.py: WSGI application entry point.
- __init__.py: Identifies the directory as a Python package.

## 7. Creating a Django Application

A Django project can contain multiple applications.

Create an application:

```bash
python manage.py startapp blog
```

A typical application contains:

```text
blog/
    migrations/
    __init__.py
    admin.py
    apps.py
    models.py
    tests.py
    views.py
```

Each application can manage a particular part of a larger project.

For example, an e-commerce project might contain separate applications for users, products, orders, and payments.

## 8. Django MTV Architecture

Django follows the Model-Template-View architecture.

### Model

Models define the structure of application data. They represent database tables and provide methods to interact with stored information.

### Template

Templates control how information is displayed to users. Django templates support HTML, variables, loops, conditions, and template inheritance.

### View

Views handle incoming requests, process application logic, interact with models, and return responses.

The MTV architecture helps developers organize application code into separate responsibilities.

## 9. Django Models and Database

Django includes an Object Relational Mapper that allows developers to interact with databases using Python code.

Example model:

```python
from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    age = models.IntegerField()
    email = models.EmailField()

    def __str__(self):
        return self.name
```

Create database migrations:

```bash
python manage.py makemigrations
```

Apply migrations:

```bash
python manage.py migrate
```

Django supports databases such as SQLite, PostgreSQL, and MySQL.

## 10. Django Views

Views contain the logic that processes user requests.

Example:

```python
from django.http import HttpResponse

def home(request):
    return HttpResponse("Welcome to Django Development!")
```

Views can return HTML pages, JSON responses, redirects, and other HTTP responses.

## 11. Django URL Routing

URL routing connects website addresses to specific views.

Example:

```python
from django.urls import path
from . import views

urlpatterns = [
    path('', views.home, name='home'),
]
```

The URL configuration determines which view should handle a particular request.

## 12. Django Templates

Django templates allow developers to generate dynamic HTML pages.

Example:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Django Website</title>
</head>
<body>
    <h1>Welcome {{ name }}</h1>
</body>
</html>
```

Templates support variables, loops, conditions, filters, and inheritance.

Template inheritance helps developers reuse common layouts across multiple pages.

## 13. Django Admin Panel

One of Django's most useful features is its built-in administration interface.

Create a superuser:

```bash
python manage.py createsuperuser
```

Register a model in admin.py:

```python
from django.contrib import admin
from .models import Student

admin.site.register(Student)
```

Start the development server and visit:

http://127.0.0.1:8000/admin/

The admin panel allows authorized administrators to manage application data through a web interface.

## 14. Django Forms

Django forms help developers collect and validate user input.

Forms can be used for:

- User registration.
- Login pages.
- Contact forms.
- Feedback forms.
- Search functionality.
- Data entry.

Django provides built-in form validation features that help reduce repetitive coding.

## 15. Django Authentication

Django includes a built-in authentication system.

It supports:

- User registration.
- Login and logout.
- Password hashing.
- Password reset.
- User permissions.
- Groups and authorization.

Authentication verifies user identity, while authorization determines what an authenticated user is allowed to do.

## 16. Django REST Framework

Django REST Framework (DRF) is a popular toolkit for building Web APIs using Django.

It provides:

- Serializers.
- API views.
- ViewSets.
- Authentication.
- Permissions.
- Pagination.
- Browsable API.
- Request validation.

Example installation:

```bash
pip install djangorestframework
```

Add `rest_framework` to INSTALLED_APPS in settings.py.

DRF is commonly used to build backend services for mobile applications and frontend frameworks such as React and Angular.

## 17. Django Security

Security is an important part of web application development.

Django provides built-in protection against several common security risks.

Important security features include:

- Cross-Site Request Forgery protection.
- Cross-Site Scripting protection through template escaping.
- SQL injection protection through ORM query handling.
- Secure password hashing.
- Host header validation.
- HTTPS deployment support.

Developers should also protect secret keys, validate user input, configure permissions correctly, and keep dependencies updated.

## 18. Django Deployment

Deployment means making a Django application available to users over the internet.

Common deployment components include:

- Linux server.
- Python virtual environment.
- Gunicorn or another suitable application server.
- Nginx as a reverse proxy.
- PostgreSQL database.
- Domain name.
- HTTPS certificate.
- Environment variables.
- Application logging and monitoring.

Cloud platforms such as AWS, Azure, and Google Cloud can be used to host Django applications.

For production, developers should disable DEBUG mode, configure ALLOWED_HOSTS, protect SECRET_KEY, and run database migrations.

## 19. Django and DevOps

Django applications can be integrated with DevOps tools to automate development and deployment.

Useful tools include:

- Git and GitHub for version control.
- Jenkins and GitHub Actions for CI/CD.
- Docker for containerization.
- Kubernetes for container orchestration.
- Terraform for infrastructure management.
- Ansible for configuration management.
- AWS for cloud hosting.
- Prometheus and Grafana for monitoring.

These tools help development teams build, test, deploy, and maintain Django applications efficiently.
